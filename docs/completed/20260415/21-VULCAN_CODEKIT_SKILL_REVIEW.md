# 任务目标

对当前 `vulcan-codekit` 技能组进行一次全盘审核，重点检查各工具的参数协议、返回格式、实现逻辑、测试覆盖与文档说明之间是否存在不一致、回归风险或潜在缺陷，并形成结构化审查结论。

# 执行步骤

1. 梳理 `vulcan-codekit` 的核心技能入口、工具定义与配套文档，建立整体结构视图。
2. 重点审查 `codekit-ast`、`codekit-rg`、`codekit-markdown-menu`、`codekit-ast-tree`、`codekit-patch` 的参数、输出和职责边界。
3. 检查当前实现与 `skill.json`、`docs/lua_skills.md`、guide/template 示例之间是否一致。
4. 结合已有回归脚本与必要的实际调用，识别明显的行为缺陷、误导性文档和测试空洞。
5. 输出按严重度排序的审核发现，并补充执行变更总结后归档计划文件。

# 技术选型

- 以代码审查模式执行本次任务，优先识别真实缺陷、行为回归风险与说明不一致问题，而不是做泛泛概览。
- 优先使用 AST 结构分析建立技能组全局视图，再配合定点读取和必要的实际调用验证。
- 本次任务以审查结论为主，不默认修改代码；若发现问题，先形成结论与定位依据。

# 验收标准

- 对 `vulcan-codekit` 技能组的关键工具形成结构化审核结论。
- 审核结果包含明确的问题定位、影响说明与文件引用。
- 明确说明未发现问题的区域和残余风险/测试缺口。
- 计划文件完成执行总结并归档。
