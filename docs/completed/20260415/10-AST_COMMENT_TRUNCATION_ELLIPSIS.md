# 任务目标

调整 `vulcan-codekit` 中 AST 备注摘要的截断行为：当备注内容因长度限制被截断时，在结果末尾追加 `...`，避免阅读时出现语义断层。

# 执行步骤

1. 定位 `comment=true` 场景下备注摘要与 UTF-8 安全截断的实现位置。
2. 调整截断逻辑，使仅在实际发生截断时追加省略号，并继续保持 UTF-8 安全。
3. 进行最小必要验证，确认未截断内容不受影响，截断内容末尾新增 `...`。
4. 补充执行变更总结，并按规范归档到 `docs/completed/20260415/`。

# 技术选型

- 保持现有 UTF-8 安全截断实现不变，优先在摘要层补充“是否发生截断”的判断。
- 仅在真实超限时追加 ASCII 省略号 `...`，避免对未截断备注产生噪音。
- 采用最小范围改动，避免影响已有注释清洗与摘要压缩规则。

# 验收标准

1. AST 备注摘要在发生截断时，返回文本末尾带有 `...`。
2. 未发生截断的备注内容保持原样，不追加省略号。
3. UTF-8 安全截断能力仍然有效，不引入乱码或半个中文字符。
4. 计划文件在任务完成后补齐执行变更总结，并归档到 `docs/completed/20260415/`。
