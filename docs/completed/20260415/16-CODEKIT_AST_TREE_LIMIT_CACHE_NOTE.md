# 任务目标

为 `codekit-ast-tree` 增加输出字符上限控制：当生成的目录树文本总字符超过当前限制时，不直接内联完整内容，而是在返回内容中增加缓存获取地址备注信息，帮助后续根据缓存地址继续读取完整结果。

# 执行步骤

1. 梳理 `codekit-ast-tree` 当前输出路径，确认在哪里最适合接入字符上限判断。
2. 复用现有 `codekit-ast` 的客户端字符上限初始化或等价逻辑，确保不同客户端能使用不同阈值。
3. 实现超限分支：
   - 将完整文本写入缓存目录；
   - 返回精简内容，并附带缓存获取地址备注信息；
   - 未超限时仍保持原有纯文本输出。
4. 进行真实调用验证，覆盖未超限与超限两种场景。
5. 完成执行总结并归档计划文件。

# 技术选型

- 优先复用 `vulcan.temp_dir/mcp/cache/` 作为缓存落点，保持与现有 codekit 工具大结果落盘策略一致。
- 在 `codekit-ast-tree` 内部直接做字符串长度判断与缓存写入，避免引入额外中间层。
- 返回内容仍保持 Markdown 风格文本，只在超限时附加缓存地址与说明，不返回复杂结构体。

# 验收标准

- `codekit-ast-tree` 在未超限时保持纯文本正常输出。
- `codekit-ast-tree` 在超限时能成功写入缓存文件，并在返回文本中附带明确的缓存地址备注。
- 缓存地址使用绝对路径，便于后续精确获取。
- 实际调用验证通过。

# 执行变更总结

## 1. 核心修复与调整概述

- 为 `codekit-ast-tree` 增加了与 `codekit-ast` 同口径的字符预算判断逻辑。
- 当输出文本超过当前 AST 客户端预算时，工具会先把完整结果写入 `vulcan.temp_dir/mcp/cache/`，再把缓存地址备注前置到返回正文顶部。
- 未超限场景保持原有纯文本目录树输出，不引入额外包装结构。
