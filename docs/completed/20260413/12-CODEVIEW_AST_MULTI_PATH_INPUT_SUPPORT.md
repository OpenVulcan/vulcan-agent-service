# 任务目标

为 `codeview_ast` 增加多路径输入能力，使 `path` 参数既可以传入单个文件/目录路径，也可以传入多行路径列表。系统需要按路径逐项处理，并对不存在或无效的路径返回明确错误信息，避免因 AI 未换行或参数拼接错误导致问题难以定位。

# 执行步骤

1. 审查现有 `codeview_ast` 的参数校验与文件收集流程，定位单路径假设所在位置。
2. 将 `path` 参数解析重构为“路径列表”模式，兼容单路径输入与按行分隔的多路径输入。
3. 调整文件收集逻辑，支持逐路径处理、聚合结果、保留逐路径错误，并避免重复文件重复输出。
4. 保持既有单文件/目录行为约束不变：
   - 文件模式下忽略 `recursive` 与 `ext`
   - 目录模式下才应用 `recursive` 与 `ext`
5. 更新 `skill.json` 的参数描述，明确 `path` 支持多行输入。
6. 通过构建与实际调用验证以下场景：
   - 单文件路径
   - 单目录路径
   - 多文件/多目录混合路径
   - 含不存在路径的混合输入

# 技术选型

- 继续在 Lua 层实现参数解析与聚合，避免扩大 Rust 侧接口变更范围。
- 复用现有单路径收集逻辑，拆分为更细粒度的“单路径处理 + 多路径聚合”结构，降低回归风险。
- 以“每行一个路径”为主输入格式，不按空格拆分，防止误伤带空格路径。
- 对重复文件按规范化后的绝对路径去重，确保多路径重叠扫描时输出稳定。

# 验收标准

1. `path` 传入单个路径时，结果与现有行为保持兼容。
2. `path` 传入多行路径时，系统能正确聚合多个文件/目录的结构结果。
3. 不存在的路径不会导致整个调用失败，而是进入错误列表并带有明确路径信息。
4. 同一文件被重复传入、或被目录与文件路径同时覆盖时，最终输出中仅保留一份。
5. 构建通过，且真实 MCP 调用验证通过。

# 执行变更总结

## 1. 核心修复与调整概述

- 将 `codeview_ast` 的 `path` 参数从“仅支持单路径”扩展为“支持单路径或多行路径列表”。
- 保持原有模式语义不变：文件输入仍忽略 `recursive/ext`，目录输入才应用 `recursive/ext`。
- 文件收集链路重构为“单路径收集 + 多路径聚合”，并按规范化后的绝对路径去重，解决目录与文件路径重叠时的重复输出问题。
- 路径错误不再中断整个调用；不存在路径会进入返回结果中的 `errors` 列表，便于 AI 识别是漏换行还是路径本身错误。

## 3. 💻关键代码调整详情

- 在 `main.lua` 中新增 `collect_files_for_path(...)`，保留原有单路径文件/目录判断与扫描规则。
- 在 `main.lua` 中重写 `collect_files(...)`，使其支持遍历路径列表、聚合文件项、按绝对路径去重，并收集逐路径错误。
- 在 `main.lua` 中调整 `validate_path_argument(...)`，将字符串输入按换行切分为路径数组，忽略空行，并在空输入时返回结构化参数错误。
- 在技能返回结果中新增 `paths` 字段，用于显式暴露规范化后的路径列表；同时保留 `path` 字段，兼容既有单路径认知。
- 在 `skill.json` 中更新参数与 prompt 描述，明确多行路径输入语义以及无效路径的返回方式。

## 4. ⚠️遗留问题与注意事项

- 当前多路径输入仍以“每行一个路径”为唯一官方格式，不按空格拆分；如果 AI 把多个路径拼成一整行，会按单个错误路径返回 `path_not_found`，这是当前设计的预期行为。
- 结果中的去重依据是规范化后的实际文件路径，因此当文件路径与目录路径同时覆盖到同一文件时，最终只保留一份结构结果。
- 本轮仅扩展了输入与聚合层，没有调整 AST 规则本身；如果某些语言结构缺失，仍需要在对应规则文件中单独补强。
- 实测验证结果：
  - 构建：`scripts/build.ps1` 成功。
  - 真实 MCP 回归一：文件 + 同目录 + 不存在路径混合输入时，返回 `files_scanned = 1`、`files_with_symbols = 1`、`returned_paths = 3`、`path_not_found_errors = 1`，且 `main.lua` 仅出现 1 次。
  - 真实 MCP 回归二：两个不同 Rust 文件 + 不存在路径混合输入时，返回 `files_scanned = 2`、`files_with_symbols = 2`、`returned_paths = 3`、`path_not_found_errors = 1`。
