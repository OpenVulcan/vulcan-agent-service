# 任务目标

对 `vldb-sqlite` 与 `vldb-lancedb` 两个仓库执行标签重置：

1. 删除本地与远端所有既有 tag；
2. 基于当前代码状态重新创建并推送当前版本号对应的 tag；
3. 确保两个仓库的发布标签与当前提交状态重新对齐。

# 执行步骤

1. 盘点两个仓库的本地与远端 tag 列表。
2. 读取两个仓库当前 `Cargo.toml` 版本号，作为重建 tag 的依据。
3. 删除两个仓库本地所有旧 tag。
4. 删除两个仓库远端所有旧 tag。
5. 重新创建：
   - `vldb-sqlite`：`v<当前版本>`
   - `vldb-lancedb`：`v<当前版本>`
6. 推送新 tag，并复核远端状态。
7. 在计划文件末尾补充执行变更总结，随后归档。

# 技术选型

1. 采用显式 `git tag -d` 与 `git push origin :refs/tags/<tag>` 的方式删除标签，避免误删分支。
2. 以 `Cargo.toml` 当前版本号作为唯一重建依据，不复用旧 tag 指向。
3. 不改动代码提交，仅处理 tag 层。

# 验收标准

1. 两个仓库本地旧 tag 全部删除。
2. 两个仓库远端旧 tag 全部删除。
3. 两个仓库均只保留当前版本号对应的新 tag。
